# VedaGPT

VedaGPT is a source-grounded educational RAG application for understanding selected Indian scriptures.

## Current phase

Phase 1: Bhagavad Gita RAG proof of concept using:

- FastAPI
- Qdrant
- Claude
- Multilingual embeddings
- Structured citations
- Citation validation
